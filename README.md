# Flower — символический 3D-эффект

Адаптивная анимация цветка, собранного из букв, цифр и символов клавиатуры.

## Структура

- `index.html` — разметка страницы
- `css/style.css` — оформление и эффекты экрана
- `js/main.js` — 3D-анимация на Three.js

## Как открыть в Visual Studio Code

1. Распакуй архив в отдельную папку.
2. Открой эту папку в Visual Studio Code.
3. Установи расширение **Live Server** (если ещё не установлено).
4. Нажми правой кнопкой на `index.html` → **Open with Live Server**.

Для работы Three.js нужен интернет, потому что библиотека загружается с CDN.

## Как поделиться сайтом

Самый простой способ — загрузить папку проекта в GitHub и включить GitHub Pages:
1. Создай репозиторий на GitHub и загрузи все файлы и папки проекта.
2. Открой **Settings → Pages**.
3. В разделе публикации выбери ветку `main` и папку `/ (root)`.
4. Сохрани настройки. GitHub выдаст публичную ссылку, которую можно отправить кому угодно.

После публикации сайт будет открываться по ссылке на телефоне, планшете и компьютере.
Для публичной ссылки не отправляй только `index.html`: нужны также папки `css` и `js`.
